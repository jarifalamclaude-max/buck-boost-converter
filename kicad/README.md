# SafeBuck-80 KiCad project

Open `SafeBuck-80.kicad_pro` in KiCad 7 (or newer). It contains the schematic and the routed 2-layer PCB.
The project libraries (`SafeBuck.kicad_sym`, `SafeBuck.pretty`) load automatically; all other symbols and
footprints are from the standard KiCad libraries.

`SafeBuck-80_KiCad.zip` holds the same files in one download.

This folder is a copy made by `hardware/make_jlcpcb.py`; the scripts in `hardware/` generate the originals.
