SafeBuck-80 — Noob-friendly Build Guide

Kono experience chhara-i: file download → JLCPCB order → first power-up → CV/CC set → protection test.
Safety: eta 80 W power supply. 36 V porjonto DC safe, kintu short-circuit e cable gorom hoy, battery theke boro spark hoy. Prothombar sobsomoy current-limited bench supply diye chalaben. Box er bhitore ba gorom jaygay ghonta dhore 80 W chalale heatsink lagan.

0. Ki ki lagbe

  • Ei repo (GitHub page e Code → Download ZIP).
  • Bench power supply (0–30 V, current limit shoho). Na thakle 12 V adapter + 2 A fuse.
  • Multimeter (10 A range shoho), ekta load (12 V bulb / 10 Ω 25 W resistor), 1.5 mm² (16 AWG) wire.
  • Box er bhitore / 40 °C er beshi gorome full power er jonno: 40×40×10 mm aluminium heatsink, 1 mm thermal pad, 3× M3 screw + nylon spacer.
  • Nije solder korle (Option B): hot-air station, solder paste, flux, tweezers — U1/U2 hand solder kora kothin.

1. JLCPCB te order (Option A — recommended)

  1. jlcpcb.com → Order Now → Add gerber file → jlcpcb/SafeBuck-80_gerbers.zip upload.
  2. Settings: Layers 2, Dimension auto (72 × 54 mm), PCB Thickness 1.6 mm, Outer Copper Weight 2 oz (khub important), Surface finish HASL lead-free ba ENIG, color jekono.
  3. PCB Assembly on → Top side → PCBA type Standard (extended part ar through-hole part er jonno lagbe) → quantity 2 ba 5.
  4. Next → BOM: jlcpcb/SafeBuck-80_BOM.csv, CPL: jlcpcb/SafeBuck-80_CPL.csv upload.
  5. Part list e protita line "matched" kina dekhun (LCSC number already deya). Kono part out of stock dekhale same value/package er onno part select korun — U1, U2, Q1–Q7, L1, R15, R31 change korben na (egula exact lagbe).
  6. Placement preview khub mon diye dekhun: U1/U2 er pin-1 dot, MOSFET, diode/LED er dag (cathode), C11/C18 er + side silkscreen er sathe milche kina. Ulta dekhale oi part er rotation 90/180 ghuran. Order e "Confirm Parts Placement" option thakle select korun — JLC engineer check kore pathabe.
  7. J1, J2 (screw terminal) ar RV1, RV2 (pot) through-hole part: JLC ke diye lagaben (THT assembly) othoba BOM theke bad diye nije solder korben (shohoj).
  8. Order + payment. Shadharonoto 1–2 shoptaho.

2. Nije assemble (Option B — experienced der jonno)

Order: U2 (QFN) → U1 (TSSOP-EP, exposed pad e paste) → Q1–Q7 → L1 → baki SMD → J1, J2, RV1, RV2. Stencil + hot air/reflow use korun. U1 er exposed pad GND e solder na hole IC gorom hoye bondho hobe.

3. Prothom check (power chhara)

  1. Magnifier diye U1/U2 er pin e solder bridge ache kina.
  2. Multimeter (resistance): J1 + theke − : > 1 kΩ hote hobe (short na). J2 + theke −: > 1 kΩ.
  3. C11, C18 er + chinho, LED gulo silkscreen er sathe milche kina.

4. First power-up (smoke test, step by step)

  1. RV1 (CV) counter-clockwise 25 paak ghurie minimum e rakhun (output ~1.6 V). RV2 (CC) majhamajhi.
  2. Bench supply: 12 V, current limit 0.2 A. J1 er + ar − (silkscreen dekhun) e lagan, J2 te kichu na.
  3. Expected: green LED jolbe, red LED gulo bondho, input current ~20–40 mA. Kichu gorom hobe na.
  4. J2 te multimeter: ~1.6 V. RV1 clockwise ghuran → voltage barbe (25 paak e full range ~1.6–39 V; 36 V er beshi set korben na). (Kono kono 3296 pot e direction ulta — meter dekhe bujhun.)
  5. 12 V set kore load (bulb) lagan, supply current limit 3 A koren. Bulb jolbe, voltage thik thakbe.
  6. CC set: load khule, J2 te multimeter (10 A range) direct lagan (short) → current dekhaben → RV2 ghurie jei current limit chan set korun (0.9–8.3 A).

6. Full power (80 W)

  • Board er niche heatsink: thermal pad diye MOSFET/U1 area er bottom side heatsink e chepe lagan, M3 nylon spacer.
  • Input wire 1.5 mm² (9 V e 9.5 A input current), terminal screw tight.
  • Max: 8.3 A (CC max) ar 80 W — duto limit-i manben (jemon 24 V e 3.3 A).
  • Board 105 °C hole TH1 nije current komay; eta hole heatsink/airflow baran.
